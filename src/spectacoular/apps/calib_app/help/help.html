Getting Started

Step 1: Select Source
First, in the control panel select the correct source in the source selector. The Phantom option replays a test file (used in development) and can be used to test the application when no microphone is connected. If your source doesn't appear, ensure you have installed the correct drivers and the microphone is connected.

Step 2: Configure Channels
Use the Parameter Panel to set values for each channel. Ensure all channels you will be using are configured with the correct parameters. You can use the "All" setter to configure all channels at once (this overwrites all channel settings!).

Step 3: Start Calibration
Once all channels are set, you can start calibration in two ways:

  • Manual: Switch to "Edit/Select" mode and click the "Start" button at the top to calibrate the currently selected channel.
  • Automatic: Switch to "Automatic" mode and press "Start". The routine will select the loudest channel and calibrate it automatically.

Step 4: Monitor Results
While calibration runs, you can see:

  • The current calibration factor
  • The stability of the factor
  • Once stable, the final calibration value in the results section at the bottom of the Parameter Panel

Step 5: Save Results

  • Click save: Saves the current table configuration
  • Location and file name are specified in "Save Path" input
    This may overwrite your specified file without confirmation

Control Panel

The control panel has 4 functions: Starting and stopping the calibration process, saving and loading an experiment setup, selecting the correct audio source and modifying which panels are displayed.

Start-Stop
The Start button starts the calibration process. The calibration mode is started in the mode and for the channel that is selected in the parameter panel.

Save-Load
Save the current configuration (calibration values, filter and calibration settings, and the notes) to a json file. The location of the file can be specified in the Save Path field. You can also load a file by clicking on the browse field in the Load File section.

This will overwrite your current configuration unless saved prior; your configuration may be lost.

Select Audio Source
The audio source selector allows you to choose which audio input device the calibration app will use. This is essential for ensuring the application receives audio from the correct microphone or input source.

Available Options:

  • Physical Microphones: Any connected USB, analog, or digital microphones will appear here once properly installed and recognized by your system.
  • Phantom Source: A built-in test option that replays a pre-recorded test file. This is primarily used for development and testing purposes when no physical microphone is connected. It allows you to verify the application's functionality without requiring actual audio input.

Troubleshooting:

  • If your microphone does not appear in the list, first verify it is properly connected to your computer.
  • Ensure the correct drivers are installed for your audio device.
  • Try restarting the application after connecting or enabling your microphone.

Display Options
Toggle switches to show or hide the panels to the right of the Control Panel. This allows you to customize your workspace and focus on the information you need.

Disabling panels such as the Graph (FFT) can improve performance.

Parameter Panel

The Parameter Panel is the central hub for configuring calibration settings for each channel and monitoring calibration results in real-time.

Operation Modes:

  • Edit/Select Mode: Manually select and configure individual channels. Use the channel dropdown to pick a specific channel, set its parameters, and click "Set" to apply. To calibrate, ensure the channel is selected and click "Start" in the Control Panel.
  • Automatic Mode: The system automatically detects the loudest (most active) channel and initiates calibration on that channel. The selected channel updates automatically during calibration.

Channel Selection:

  • Individual Channels: Select "Channel 1", "Channel 2", etc. to configure a specific channel's parameters.
  • All Channels: Select "All" to apply the same parameter values to every channel simultaneously.
    Warning: This overwrites all existing channel configurations without confirmation. Use with caution.

Calibration Parameters:

  • Calibration Level: The reference level of your calibrator device (e.g., 94 dB). This is the known output level that your calibrator produces, which the application uses as a reference point for calculating calibration factors.
  • Level Unit: The unit of measurement for your calibration level. Select from:
    • dB - Decibels (sound pressure level)
    • N - Newtons (force)
    • m/s² - Meters per second squared (acceleration)
These different units allow the application to work with various sensor types, such as microphones (using dB) and acceleration sensors (using m/s²).
  • Calibration Frequency (Hz): The frequency at which your calibrator operates (e.g., 1000 Hz). This frequency is then used to filter only for the calibration signal
  • Filter: The weighting filter applied to the audio signal. Currently supports:
    • Octavefilter - Standard octave band filtering for acoustic measurements
  • Calibration Time (s): The duration (in seconds) that the incoming signal must remain stable before the application considers the calibration complete and saves the final value.
  • Stability Tolerance: The maximum allowed relative spread (standard deviation divided by mean) of measurement blocks to be considered stable. Lower values require more stable signals. The default is 5.8%.

Set Button: Click to apply the configured parameter values to the selected channel(s).

Result Monitoring:

  • Calibration Factor: Displays the currently computed calibration factor (calculated as: reference level ÷ mean measured value). This updates in real-time during calibration and allows the user to judge stability manually.
  • SAVED: Shows the final, saved calibration value once the signal has stabilized and the calibration is complete.
  • Stability Status: Indicates whether the current signal is STABLE (green) or UNSTABLE (orange). The signal is considered stable when the relative spread of the latest measurement blocks falls below the Stability Tolerance threshold. Once stable for the full Calibration Time duration, the calibration factor is saved.

Data Table

The Data Table provides a comprehensive overview of all channel configurations and calibration results in a tabular format.

Columns:

  • Channel: The channel identifier (e.g., CH 1, CH 2). Channels are displayed in numerical order with automatic padding for consistent alignment.
  • Calib. Factor: The determined calibration factor for each channel, displayed with 4 decimal places precision. If uncalibrated, this value defaults to 0.
  • Calib. Freq.: The calibration frequency configured for each channel, shown with 1 decimal place.
  • Calib. Lvl.: The calibration level (magnitude) set for each channel, displayed with 4 decimal places precision.
  • Calib. Lvl. Unit: The unit of measurement for the calibration level (dB, N, or m/s²).
  • Calib. Time (s): The calibration time setting for each channel, indicating how long the signal must remain stable before calibration is considered complete.
  • Stab. Tol. (dB): The stability tolerance in dB indicates how much the standard deviation can deviate from the mean for the calibration to still be considered stable.
As there is currently a bug in Bokeh's DataTable/DataSource interaction where the table does not update automatically, you can force a refresh by either scrolling entries on and off screen, or sorting the table twice by the Channel column.
For more information on each parameter see Parameter Panel above

Notes

A dedicated text area for documenting experiment details, observations, and any additional information. Notes are saved along with the configuration when you use the Save function in the Control Panel, making it easy to keep a record of your calibration sessions.

Logs

The Logs panel displays real-time application messages, including system events, calibration progress, and error notifications. Each entry is timestamped to help track the sequence of operations. Use the logs for debugging issues or verifying that operations completed as expected. the logs are also saved to calibration.log in the root of the project
